The Complete Agent Optimization Stack

Everything you need to keep AI coding assistants lean, fast, and secure.

⚡

Subshell Accelerator

Eliminates the 500ms shell init penalty on every tool execution. Injects zero-overhead bypass guards into ~/.zshrc so agent subshells spawn in under 6ms.

🔌

MCP Schema Profiler

Measures the exact token footprint of all connected Model Context Protocol tool schemas before they eat up 15k+ tokens of your system prompt.

🎯

Skills & Keyword Auditor

Audits all installed skills across Claude Code and OpenCode. Detects trigger keyword collisions and flags oversized SKILL.md definitions.

🔍

Rule Contradiction Linter

Pinpoints conflicting instructions across AGENTS.md, CLAUDE.md, and .cursorrules that trigger model confusion and infinite loops.

🖥️

Interactive Terminal UI

Full-screen dashboard with tabbed views for instant context monitoring, MCP inspection, and 1-key automated fixes.

🛡️

Ignore & Security Shield

Detects unignored build directories (.build/, DerivedData/, node_modules/) and protects exposed secrets (.env, .pem) from agent ingestion.
